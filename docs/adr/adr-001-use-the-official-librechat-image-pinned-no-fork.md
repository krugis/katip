# ADR-001: Use the official LibreChat image, pinned; no fork

- **Status:** Accepted
- **Date:** 2026-10-31

## Decision

Use the **official LibreChat image**, pinned; no fork

## Rationale and consequences

Cheap upgrades. All customisation goes through yaml, env, custom endpoints, MCP and OIDC
