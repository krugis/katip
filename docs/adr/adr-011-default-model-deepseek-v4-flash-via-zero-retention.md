# ADR-011: Default model DeepSeek V4 Flash via zero-retention providers (DeepInfra); the DeepSeek first-party endpoint is blocked

- **Status:** Accepted
- **Date:** 2026-10-31

## Decision

Default model **DeepSeek V4 Flash via zero-retention providers** (DeepInfra); the DeepSeek first-party endpoint is blocked

## Rationale and consequences

About $0.27–0.32 per typical user per month; OpenRouter lists DeepSeek's own endpoint as "may train"

Source: [docs/DESIGN.md](../DESIGN.md) §3.
