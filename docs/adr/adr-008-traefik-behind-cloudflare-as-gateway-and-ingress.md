# ADR-008: Traefik behind Cloudflare as gateway and ingress

- **Status:** Accepted
- **Date:** 2026-10-31

## Decision

**Traefik** behind **Cloudflare** as gateway and ingress

## Rationale and consequences

Docker labels, automatic TLS, IP allowlist and rate-limit middlewares
